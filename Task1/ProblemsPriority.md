# Задание 3 Приоритизируйте выявленные проблемы

## Дисклеймер

Судя по заданию видимо предполагается приоритезация фич, а не проблем.
Т.е. есть ряд проблем, обозначенных заказчиком. Приоритет этих проблем определяет заказчик.
Далее Архитектор предлагает решение, которое разбивается задачам, у которых и будет приорит в рамках роадмапа внедрения.

Сделаю исходя из задачи. Метод MoSCoW.
